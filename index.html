B2B Platform Architecture

Lextech: 9-Microservice Team Collaboration Suite

Operational Challenge

An operational team required a unified internal platform spanning task assignment, realtime document review, client communication, and accounting without recurring seat licenses from commercial SaaS platforms. The system needed to function reliably even when office network connections dropped.

Architectural Solution

Deployed a decomposed service architecture composed of 9 isolated FastAPI services communicating through Redis pub/sub. Implemented PostgreSQL 16 with row-level security for multi-tenant isolation, coupled with a Flutter client running local SQLite caches that synchronize bidirectionally upon reconnection.

9 Independent Microservices
<200ms P95 API Response Time
100% Offline Read & Write Availability
FastAPI Next.js PostgreSQL 16 Redis Flutter Docker

Lemaire: Atelier Measurement & Pattern System

Operational Challenge

A bespoke fashion atelier tracked over 400 client anatomical measurements in paper notebooks and scattered spreadsheet records. Retrieving past fitting records required several minutes of searching, resulting in fitting errors and delayed garment completions.

Architectural Solution
